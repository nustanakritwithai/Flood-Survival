# Flood Survival

เว็บเกม/interactive chronicle สำหรับถ่ายทอดเหตุการณ์น้ำท่วมจริงในพื้นที่คลองประเวศบุรีรมย์ในรูปแบบ isometric 3D แบบ mobile-first โดยแยกข้อมูล **OFFICIAL / FIELD REPORT / ESTIMATE / SIMULATION** อย่างชัดเจน

> Baseline repository initialized for the Flood Survival MVP.

## Safety principle

เกมนี้ไม่ใช่ระบบแจ้งเตือนภัยอย่างเป็นทางการ ข้อมูลสถานการณ์ที่เปลี่ยนแปลงตามเวลาต้องตรวจสอบกับหน่วยงานทางการก่อนนำไปใช้ตัดสินใจด้านความปลอดภัย
